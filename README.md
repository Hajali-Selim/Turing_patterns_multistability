# Turing patterns multistability
Generate Turing patterns on graphs using the Gierer-Meinhardt model, and predict their multistability using the graph Laplacian spectral gaps

Published in PLOS Complex Systems (2025)<br>
"How local spectral gaps regulate the multistability of Turing patterns on graphs"<br>
Haj Ali, Selim; Hütt, Marc-Thorsten<br>
https://journals.plos.org/complexsystems/article?id=10.1371/journal.pcsy.0000044 (open-source)
